# BootFlow OS Security Policy

## Supported versions

BootFlow OS is an early-stage project. Only the most recent published release is considered for project-specific security fixes. Upstream Ubuntu, Linux, GNOME, Brave, Kali, and other third-party components follow their own support and disclosure policies.

## Reporting a vulnerability

Do not open a public Issue or Discussion for an unpatched vulnerability.

Email [BootFlowOS@Proton.me](mailto:BootFlowOS@Proton.me) with the subject `SECURITY: brief description` and include:

- Affected BootFlow OS version
- Affected project-owned file or component
- Reproduction steps or proof of concept
- Expected and observed behavior
- Potential impact
- Suggested mitigation, if known

Remove passwords, tokens, private keys, personal data, and unrelated logs before sending a report. Do not attach malware or destructive payloads without prior agreement.

## Disclosure process

The project will acknowledge reports when possible, investigate, coordinate a fix, and publish an advisory or release note after users have a reasonable mitigation path. Please allow time for investigation before public disclosure.

## Scope

This policy primarily covers BootFlow-owned scripts, configuration, branding integration, release tooling, and documentation. Vulnerabilities in upstream packages should also be reported to the appropriate upstream security team.

Only test systems you own or are explicitly authorized to test.
