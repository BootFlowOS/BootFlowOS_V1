# BootFlow OS V1

Initial BootFlow OS public release.

## Desktop

- BootFlow OS V1 system branding
- BootFlow boot/shutdown branding
- BootFlow desktop/session branding
- Bottom GNOME dock
- Dock maximum icon size set to 38 px
- Custom BootFlow Start / Applications icon

## Applications

- Brave browser included
- Firefox transition package removed
- Thunderbird removed

## Base system

BootFlow OS V1 is Ubuntu-based. Internal Ubuntu-compatible identifiers may remain where required for compatibility.

## Download format

The ISO is split into multiple release assets because the complete ISO is larger than GitHub's single release-asset file limit.

Download every part, concatenate the parts in filename order, and verify the final ISO against `SHA256SUMS.txt`.
