# Contributing

Contributions to BootFlow-owned GPL-licensed code are welcome.

1. Fork the repository.
2. Create a branch.
3. Make a focused change.
4. Test it.
5. Update documentation if needed.
6. Open a pull request.

By submitting code, you agree that your contribution may be distributed under GPL-3.0-only where applicable.

Do not submit secrets, private keys, passwords, or material you do not have permission to redistribute.
